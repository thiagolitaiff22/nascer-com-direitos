# Nascer com Direitos

Sistema de controle do salário-maternidade: cadastro das clientes, requerimento no INSS, ação na Justiça, audiências, avisos por WhatsApp, financeiro (30% do benefício + guia) e arquivo.

- Sistema da equipe: `index.html` + `config.js` (HTML e JavaScript, sem etapa de build)
- Aplicativo do prospectador: `campo.html` (PWA) e `app/` (Android)
- Banco e login: Supabase (`supabase/`, veja `supabase/LEIA-ME.md`)
- Drive e IA: `google/campo.gs`

A referência de campos, documentos e etapas está em `ESPECIFICACAO.md`.

Dados de clientes nunca devem ser enviados para este repositório.
